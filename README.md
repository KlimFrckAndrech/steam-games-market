# Steam Games Market — аналитический сайт о рынке видеоигр

Курсовая работа «Разработка веб-сайта рынка видеоигр Steam».
Статический многостраничный сайт без серверной части (HTML5, CSS3, JavaScript) о закономерностях
**выборки** из набора данных «Steam Games Dataset 2025». Сайт не предсказывает успех игры и не
рекомендует цену. Покупки на сайте нет, цены только информационные.

Автор: Клименко Александр Андреевич.

## Что умеет сайт

| Страница | Назначение |
|----------|------------|
| `index.html` | Главная: слайдер «Лучшие по отзывам» (Swiper), «Новинки», вопросы и ответы о выборке |
| `catalog.html` | Каталог: поиск, фильтры по цене, жанру, платформе, русскому языку и году, сортировка, пагинация, быстрый просмотр |
| `game.html?id=` | Карточка игры по параметру адреса: цена, платформы, шкала отзывов, скриншоты, похожие игры |
| `prices.html` | Цена и отзывы, число игр по годам и жанрам (графики Chart.js) |
| `platforms.html` | Платформы и доля игр с русским языком (графики Chart.js) |
| `wishlist.html` | Список желаемого (до 10 игр, localStorage) и калькулятор: цена со скидкой, итог, стоимость часа |
| `about.html` | Источник и версия набора, схема полей, ограничения, глоссарий, лицензии, Schema.org Dataset |

Переключатель светлой и тёмной темы сохраняется в `localStorage`. Четыре модальных окна: быстрый просмотр
игры, «Как считается доля положительных отзывов», «Ограничения данных», «Условия использования обложек»
(плюс итог списка желаемого и увеличенный скриншот).

## Подготовка данных

Скрипт: `notebooks/steam_data_prep.ipynb` (запускается в Google Colab, набор скачивается через `kagglehub`).
Результат сохраняется в `data/`. Воронка отбора:

| Шаг | Записей осталось |
|-----|------------------|
| Исходные записи | 94 948 |
| Без дубликатов по названию | 94 191 |
| Год выхода 2009–2024 (2025 в наборе неполный) | 90 065 |
| Не менее 50 отзывов (`num_reviews_total`) | 28 429 |
| Без возрастного ограничения 18+ | 28 350 |
| Без тегов для взрослых (Hentai, Nudity, Sexual Content, NSFW, Mature) | 25 835 |
| Без программ, не являющихся играми | 25 817 |
| Итоговая выборка (стратификация по году и цене, seed 42) | 1 536 |

Принятые решения:

- **Отзывы:** доля положительных пересчитывается по `positive` и `negative`; для игр без этих
  чисел берётся готовая `pct_pos_total` (поле `pctSrc`: `calc` или `steam`). Дополнительно считается индекс баланса
  отзывов от −100 до +100 (поле `balance`).
- **Цена:** доллары США; игры с ценой 0 считаются бесплатными и образуют отдельный диапазон.
- **Скидка:** поле `discount` есть в данных, но не подтверждено, учтена ли скидка в цене, поэтому
  калькулятор принимает скидку вручную. _Решение по цене и скидке уточнить после проверки._
- **Статистика по годам и жанрам** считается по всем 25 817 играм, прошедшим фильтры, и лежит в `data/prices.json`.
  Числа игр в ценовых диапазонах и годах в выборке отражают метод отбора, а не структуру рынка.
- **Обложки** загружаются с серверов Steam внешними ссылками, в репозиторий не копируются; при ошибке
  показывается заглушка.

Расхождение между `pct_pos_total` и пересчётом у многих игр превышает 10 пунктов индекса баланса, значения сайта
могут отличаться от витрины Steam. Набор собран в марте 2025 года, сегодняшние цены и отзывы другие.

## Локальный запуск

`fetch()` не работает при открытии файла двойным щелчком, нужен локальный сервер:

```
python -m http.server 8000
```

Затем открыть http://localhost:8000 (в Windows при проблемах с `python` попробуйте `py -m http.server 8000`).
