# Шрифты

Сюда кладутся файлы woff2 с кириллицей (имена заданы в `css/fonts.css`):

- `rubik-500.woff2`, `rubik-700.woff2`: заголовки (Rubik, лицензия OFL)
- `roboto-400.woff2`, `roboto-700.woff2`: основной текст (Roboto, лицензия Apache 2.0)

Пока файлов нет, сайт использует запасной системный шрифт.
